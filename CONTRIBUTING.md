# Contributing Guidelines

Thank you for contributing to open-source projects under `@isihussain`.

---

## Development Workflow

1. **Fork or Branch**: Create a focused branch prefixed with `feature/`, `fix/`, `docs/`, or `refactor/`.
2. **Follow Code Standards**:
   - Write clean, idiomatic code adhering to project architecture.
   - Maintain documentation and docstrings.
   - Avoid AI slop, filler prose, and marketing superlatives.
3. **Run Tests**: Verify all tests pass locally before opening a pull request.
4. **Pull Requests**:
   - Keep pull requests scoped to a single logical change.
   - Fill out the pull request template completely.
   - Include `Co-authored-by` trailers when pairing with collaborators.
